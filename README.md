## Backend-first, AI-aware

I build backend systems where product behavior depends on clear APIs, reliable data flow, realtime events, and practical AI automation.

Currently focused on:

- RESTful API design with TypeScript, Node.js, NestJS, Hono, Express.js, JWT, RBAC, Swagger/OpenAPI
- Data layers with PostgreSQL, MongoDB, Drizzle ORM, TypeORM, and Mongoose
- Realtime product flows with Socket.IO messaging, notifications, typing state, read markers, and presence
- Dify AI workflows for chatbot, caption generation, toxic content detection, GRI mapping, and fallback strategies
- Deployment workflows with Docker Compose, Cloudflare Workers, Vercel, Render, Cloudinary, and Postman
